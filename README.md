# TARCIN Internship Portal

Unlock The Tech, Unleash The World.

## 🌟 Overview
TARCIN is a production-grade Internship Management Platform designed to streamline the journey from application to certification. It features a robust role-based system for Admins, Mentors, and Interns.

## 🚀 Key Features
- **Smart Onboarding**: Automated profile and document submission.
- **Task Command Center**: Real-time task assignment and progress tracking.
- **Global Search**: Command palette (⌘K) for instant data access.
- **Auto-Certification**: Dynamic PDF generation with QR verification.
- **Real-time Alerts**: Live notifications via Socket.io.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Database**: PostgreSQL (Prisma ORM)
- **Styling**: Tailwind CSS & Framer Motion
- **Auth**: JWT & OTP (jose)
- **Media**: Cloudinary Integration

## 🚦 Quick Start
1. **Install**: `npm install`
2. **Database**: `npx prisma db push`
3. **Seed**: `npx prisma db seed`
4. **Run**: `npm run dev`
